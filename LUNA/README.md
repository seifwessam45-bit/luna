# LUNA — Handmade Bags & Leather Goods

## Structure

LUNA/
├── index.html
├── style.css
├── script.js
└── backend/
    └── app.py

## Run locally

1. Install Python 3.
2. Open a terminal inside the LUNA folder.
3. Install Flask:

   pip install flask

4. Start the server:

   python backend/app.py

5. Open:

   http://localhost:3000

## Notes

- The frontend is HTML + CSS + JavaScript.
- Flask/Python provides the product API and demo order/newsletter endpoints.
- The checkout is intentionally a demo. For a real store, connect a payment provider and database.
